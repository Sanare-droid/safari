# Welcome to Our Blog!

This is our first post written in **MDX**. It's a fantastic way to blend Markdown with React components.

## Key Features of MDX

- Write in Markdown for content readability.
- Embed React components directly within your Markdown.
- Leverage frontmatter for metadata like title, date, etc.

Here's an example of using a simple JSX element:
<div style={{ padding: '1rem', backgroundColor: '#e0f7fa', borderLeft: '4px solid #00bcd4', margin: '1rem 0' }}>
  <p style={{ margin: 0, color: '#00796b', fontWeight: 'bold' }}>This is a JSX block inside MDX!</p>
</div>
